### Технічний зріз T5.5 (Draft)

Навігація: звичайні посилання на чинні `/app` URL через Laravel SPA fallback, без окремого router; `api.ts` зберігає єдиний session/CSRF/error boundary, `mealPlanApi.ts` типізує повторне читання T5.2. Це не створює нових серверних API або залежностей. «Сьогодні» отримує день тільки з серверного `today` та реального чинного `/api/meal-plan/days`, а не з прикладів чи браузерного обчислення дати; рецепт відкривається за exact meal-item. Порожні дані, неавторизований запит, зміна призначення та помилка не підміняються демонстраційними. Чотири вкладки й профіль — поверх чинних екранів. Telegram/онлайн-сесія/звіт/кроки й меню-цикли не вводяться без окремих джерел і рішень. До завершення перевірок це опис запропонованого зрізу, не статус production.
